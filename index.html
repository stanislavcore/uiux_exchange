API Документация

Обменник - Telegram Mini App

Пользователи

1
Получение пользователя
POST
/api/v1/users
Входные данные
telegram_id int Telegram ID пользователя
Выходные данные
telegram_id int Telegram ID
full_name str Имя пользователя
username str username пользователя опционально
photo_url str url аватарки пользователя опционально
email str email пользователя опционально
phone str номер телефона пользователя опционально
verification_status bool статус верификации (YES/NO/PROCCESS)
notification_wallet bool нажал на уведомление крипто-кошелька
notification_card bool нажал на уведомление карты
notification_esim bool нажал на уведомление E-Sim
notification_referral bool нажал на уведомление реферальной программы
limit_min_amount int минимальная сумма на сделку экспресс в рублях
limit_max_amount int максимальная сумма на сделку экспресс в рублях
limit_day_max int доступно в день на экспресс в рублях
limit_day_spend int потрачено сегодня на экспресс в рублях
limit_month_max int доступно в месяц на экспресс в рублях
limit_month_spend int потрачено в этом месяце на экспресс в рублях
limit_day_req_max int доступно запросов в день на экспресс
limit_day_req_spend int потрачено запросов сегодня на экспресс
2
Смена почты
POST
/api/v1/users/change-email
Входные данные
telegram_id int Telegram ID пользователя
email str Новый email адрес
Выходные данные
success bool Статус успеха операции
3
Верификация
POST
/api/v1/users/verif
Входные данные
telegram_id int Telegram ID пользователя
photo_passport file Фото паспорта
photo_register file Фото регистрации
photo_selfie file Фото селфи с документом
phone_number str Номер телефона
Выходные данные
success bool Статус успеха операции (Не статус завершения верификации, а статус о принятии заявки на верификацию. Проще говоря, запрос прошёл успешно)

Заявки Безнал / Нал

1
Получение всех заявок
POST
/api/v1/orders
Входные данные
telegram_id int Telegram ID пользователя
Выходные данные (массив)
id int Номер заявки в БД
system_id str Номер заявки для пользователя
payment_method str Тип платежа (CASH / BANK)
payment_type_bank str Тип заявки для безнала (CLASSIC / EXPRESS) опционально
direction str Направление (SELL / BUY)
date str Дата создания заявки
status str Статус заявки (CREATED / PROCCESS / DONE / CANCEL)
source_currency str Отдаёт валюту
source_amount float Отдаёт сумму
destination_currency str Получает валюту
destination_amount str Получает сумму
course float Курс 1 sourse = course destination (Для внутренних подсчётов)
course_visible str Курс для показа пользователю (84.3 руб / USDT и тд)
bank_user str Банк списания или получения пользователя. Только для покупки классика и продажи экспресс опционально
address_user str Адрес приёма пользователя. Только для покупки классика и экспресс опционально
network_address_user str Сеть адреса приёма пользователя. Только для покупки классика и экспресс опционально
get_type str Метод получения руб. (SBP / CARD). Только для продажи классик опционально
get_req str Реквизит получения руб. Только для продажи классик опционально
promo str Применение промокода. Если null - промо не было, если есть - название промокода опционально
county str Страна для нал обмена опционально
city str Город для нал обмена опционально

Курсы

1
Получение курсов для классического безнал обмена
POST
/api/v1/courses/classic
Входные данные
- - Нет входных данных
Выходные данные (массив)
direction str Направление (BUY / SELL)
min_amount float Минимальная сумма для обмена в валюте. Для покупки - в RUB, для продажи - в крипте
crypto str Крипта
networks List[str] Список сетей
course float В рублях. 1 крипта = course рублей
2
Получение курсов для экспресс безнал обмена
POST
/api/v1/courses/express
Входные данные
- - Нет входных данных
Выходные данные
buy_usdt float Курс КУПИТЬ usdt в рублях
sell_usdt float Курс ПРОДАТЬ usdt в рублях
3
Получение курсов для наличного обмена
POST
/api/v1/courses/cash
Входные данные
- - Нет входных данных
Выходные данные (массив)
direction str Направление (BUY / SELL)
country str Страна
city str Город
currency str Фиат валюта
min_amount float Минимальная сумма для обмена в валюте. Для покупки - в currency, для продажи - в крипте
crypto str Крипта
networks List[str] Список сетей
course float В рублях. 1 крипта = course currency
